## پروژه را چطور اجرا کنیم؟

ابتدا پروژه را Clone کنید:

git clone https://github.com/AMIRALISHAFIEE/URL_Shortener.git

سپس وارد پوشه پروژه شوید:

cd URL_Shortener

پکیج‌های مورد نیاز را نصب کنید:

npm install

برای اجرای پروژه دستور زیر را اجرا کنید:

npm run dev

بعد از اجرا، آدرسی مشابه زیر در ترمینال نمایش داده می‌شود:

http://localhost:5173

با باز کردن این آدرس در مرورگر، پروژه اجرا می‌شود.


## از چه تکنولوژی‌هایی استفاده شده؟

در این پروژه از تکنولوژی‌های زیر استفاده شده است:

* Vue.js
* Vite
* Tailwind CSS


## چه بخش‌هایی کامل شده؟

* ساخت لینک کوتاه
* اعتبارسنجی URL
* جلوگیری از تولید لینک کوتاه تکراری
* انتخاب تاریخ انقضا
* ذخیره لینک‌ها در LocalStorage
* کپی کردن لینک کوتاه 
* نمایش پیام موفقیت و خطا   


## اگر دوباره فرصت داشتید، چه چیزی را بهتر می‌کردید؟

اگر زمان بیشتری وجود داشت، رابط کاربری پروژه را بهتر و کامل‌تر می‌کردم و امکانات بیشتری مانند:

* جستجو در تاریخچه لینک‌ها
* دسته‌بندی لینک‌ها
* تولید لینک کوتاه واقعی
* حذف خودکار لینک ها در تاریخ انقضا
* Dark Mode
* انیمیشن‌های بهتر
* بهبود تجربه کاربری (UX)

## اگر بخشی کامل نشده، دلیل آن چه بوده؟

امکان تعیین لینک کوتاه با آدرس دلخواه توسط کاربر و همچنین بخش تست‌نویسی در این پروژه پیاده‌سازی نشده‌اند. دلیل این موضوع محدود بودن زمان پروژه و تمرکز بیشتر روی پیاده‌سازی قابلیت‌های اصلی Frontend مانند ساخت لینک کوتاه، اعتبارسنجی URL، مدیریت لینک‌ها و بهبود رابط کاربری بوده است.
